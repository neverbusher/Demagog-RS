# Demagog-RS

Процессор текста и словарей для TTS (FishAudio Drama3 / ComfyUI). Подготавливает книги и большие тексты: числа и даты словами, ё-фикация, омографы, ударения, чистка и нарезка на чанки.

## Быстрый старт

1. Распакуйте архив в любую папку с правом записи. Не запускайте из `Program Files`: рядом с exe сохраняется `settings.json`.
2. Запустите `Demagog-RS.exe`. Если окно не открывается — попробуйте `Demagog-RS-wgpu.exe`.
3. Убедитесь, что рядом с exe лежит папка `dic` (она уже входит в комплект).
4. Нажмите «Открыть книгу», выберите TXT, FB2, EPUB или DOCX.
5. Выберите нужные словари и нажмите «Обработать книгу».
6. Готовый текст можно сохранить в TXT или экспортировать чанки в JSON для ComfyUI.

## Требования

- Windows 10/11 x64.
- Основной `Demagog-RS.exe` использует OpenGL 3.3; на RDP, в виртуалках и на старых драйверах он может не открыться.
- `Demagog-RS-wgpu.exe` использует DirectX 12 (при отсутствии GPU может задействоваться программный WARP).
- Visual C++ Redistributable **не требуется**: CRT собрана статически.
- Интернет не нужен.

При первом запуске Windows SmartScreen может предупредить, что издатель неизвестен: «Подробнее» → «Выполнить в любом случае». Это ожидаемо для бинарника без цифровой подписи.

## Если окно не открывается

Основная сборка рисует интерфейс через OpenGL. Если драйвер не даёт нужный контекст, приложение показывает диалог с текстом ошибки. В этом случае запустите `Demagog-RS-wgpu.exe`: он использует DirectX 12 и обычно работает там, где OpenGL недоступен. Если не запускается и он — пришлите текст ошибки из диалога.

## Что в комплекте

- `Demagog-RS.exe` — основной вариант (OpenGL).
- `Demagog-RS-wgpu.exe` — резервный вариант (DirectX 12/WARP).
- `dic/` — 29 словарей верхнего уровня (`*.rex`, `*.dic`). Папку нельзя удалять или переименовывать.
- `README` — этот файл.
- `LICENSE.txt` — текст лицензии MIT.
- `THIRD_PARTY_NOTICES.md` — лицензии сторонних библиотек.

Файл `settings.json` создаётся автоматически при выходе. В нём хранятся тема, размер шрифта, формат ударений, включённые словари и свёрнутые группы. Чтобы сбросить настройки, закройте программу и удалите `settings.json`.

## Возможности

- Группировка словарей по типам, включение/отключение группы одним чекбоксом, сохранение свёрнутости групп.
- Три формата выхода: `+` перед ударной гласной, Юникод-ударение, только «ё».
- Режим «С логом замен (Diff)» показывает, какие правила и где сработали.
- Нарезка на чанки с учётом границ предложений; настройка максимальной длины и склейки абзацев.
- Тёмная и светлая темы, масштаб шрифта.
- Пакетная обработка через CLI: `Demagog-RS.exe --cli --input book.txt --output result.txt [--diff]`.

## Исходники и Releases

В git-репозитории хранятся только исходники и документация; папка `dic/`, exe и локальные настройки исключены через `.gitignore`. Репозиторий: https://github.com/neverbusher/Demagog-RS. Готовый архив со словарями прикреплён к разделу **Releases**.

Для сборки из исходников положите словари в `dic/` рядом с `Cargo.toml` и выполните `cargo build --release` (Windows 10/11 x64, Rust stable). Сборка использует статическую CRT. DirectX-вариант собирается командой `cargo build --release --features wgpu`.

Папка `dic/tmp` в поставку не входит и приложению не нужна.
