# Demagog-RS

Процессор текста и словарей для TTS (FishAudio Drama3 / ComfyUI). Подготавливает книги и большие тексты: числа и даты словами, ё-фикация, омографы, ударения, чистка и нарезка на чанки.

## Быстрый старт

1. Распакуйте архив в любую папку с правом записи. Не запускайте из `Program Files`: рядом с exe сохраняется `settings.json`.
2. Запустите `Demagog-RS.exe`. Если окно не открывается — запустите `Demagog-RS-cpu.exe`.
3. Убедитесь, что рядом с exe лежит папка `dic` (она уже входит в комплект).
4. Нажмите «Открыть книгу», выберите TXT, FB2, EPUB или DOCX.
5. Выберите нужные словари и нажмите «Обработать».
6. Готовый текст можно сохранить в TXT или экспортировать чанки в JSON для ComfyUI.

## Требования

- Windows 10/11 x64.
- `Demagog-RS.exe` использует OpenGL 3.3 и лучше подходит для обычных машин с видеодрайвером.
- `Demagog-RS-cpu.exe` вообще не требует OpenGL, DirectX или GPU: интерфейс рисуется на процессоре. Это вариант для RDP, виртуалок и старых видеокарт (например, Intel HD Graphics 3000).
- Visual C++ Redistributable **не требуется**: CRT собрана статически.
- Интернет не нужен.

При первом запуске Windows SmartScreen может предупредить, что издатель неизвестен: «Подробнее» → «Выполнить в любом случае». Это ожидаемо для бинарника без цифровой подписи.

## Если окно не открывается

Основная сборка рисует интерфейс через OpenGL. Если драйвер не даёт нужный контекст, приложение показывает диалог с текстом ошибки. Запустите `Demagog-RS-cpu.exe` — программный рендер работает без OpenGL и DX12. Интерфейс на CPU может перерисовываться медленнее, но обработка текста и словарей остаётся такой же.

Если не запускается и CPU-версия — пришлите текст ошибки из диалога.

## Что в комплекте

- `Demagog-RS.exe` — основной вариант (OpenGL).
- `Demagog-RS-cpu.exe` — резервный вариант без OpenGL (программный рендер на CPU).
- `dic/` — 29 словарей верхнего уровня (`*.rex`, `*.dic`). Папку нельзя удалять или переименовывать.
- `README` — этот файл.
- `LICENSE.txt` — текст лицензии MIT.
- `THIRD_PARTY_NOTICES.md` — лицензии сторонних библиотек.

Файл `settings.json` создаётся автоматически при выходе. В нём хранятся тема, размер шрифта, формат ударений, включённые словари и свёрнутые группы. Сбросить настройки можно кнопкой «Сбросить настройки» в разделе «Настройки» или удалить `settings.json` при закрытой программе.

## Возможности

- Группировка словарей по типам, включение/отключение группы одним чекбоксом, сохранение свёрнутости групп.
- Три формата выхода: `+` перед ударной гласной, Юникод-ударение, только «ё».
- Режим «С журналом замен» показывает, какие правила и где сработали.
- Поиск по тексту с подсветкой (Ctrl+F), горячие клавиши и drag-and-drop книг.
- Защита несохранённой работы, отмена долгой обработки и явная пересборка устаревшего результата.
- Нарезка на чанки с учётом границ предложений; настройка максимальной длины и склейки абзацев.
- Тёмная, светлая и тёплая темы, масштаб шрифта в настройках.
- Стартовое окно подстраивается под рабочую область монитора и центрируется.
- Пакетная обработка через CLI: `Demagog-RS.exe --cli --input book.txt --output result.txt [--diff]`.

## Исходники и Releases

В git-репозитории хранятся только исходники и документация; папка `dic/`, exe и локальные настройки исключены через `.gitignore`. Репозиторий: https://github.com/neverbusher/Demagog-RS. Готовый архив со словарями прикреплён к разделу **Releases**.

Для сборки из исходников положите словари в `dic/` рядом с `Cargo.toml` и выполните:

```powershell
# OpenGL-вариант
cargo build --release

# CPU-вариант без OpenGL
cargo build --release --no-default-features --features sw
```

Windows 10/11 x64, Rust stable. Сборка использует статическую CRT.
