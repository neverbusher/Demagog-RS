# Словари: происхождение и воспроизводимость

Папка `dic/` не версионируется (см. `.gitignore`) и поставляется только в релизных
архивах. Этот документ фиксирует происхождение данных, а `assets/dictionaries.sha256`
— их состояние на момент релиза.

## Манифест

- `Demagog-RS.exe --manifest-dictionaries` пересчитывает SHA-256 всех `.dic`/`.rex`
  верхнего уровня и записывает `assets/dictionaries.sha256` (формат `<hash>  <name>`).
- `Demagog-RS.exe --check-dictionaries` сравнивает текущий набор с манифестом и
  предупреждает о дрейфе (изменён / добавлен / удалён словарь). Это привязывает
  эталонный корпус (22 фразы) к конкретному состоянию словарей.
- Манифест коммитится; сами словари — нет. При намеренном обновлении словарей
  перегенерируйте манифест и перепроверьте эталонные фразы.

## Как получены импортированные словари

Разовый импорт из `RuVoice-Stress-Converter/data/` (соседний проект):

- `stress_system.txt` → `77_`: только слова, отсутствующие в наших ударных словарях;
  при дублях берётся последнее значение; исключены слова, которые наши словари
  уже ставят или намеренно оставляют без ударения.
- `replace_system.txt` → `76_`: контекстные фразы/маски/слова, отсутствующие у нас;
  маски приведены к нашему формату (`stem*=rhs`), regex-правила и маркеры пропущены.
- `eyo_safe.txt` → `33_`: раскрытие шаблонов `слово(окончание|…)`, только отсутствующие формы.
- `hard_e.txt` → `96_`: правила `е→э` плюс варианты для слов, которые `edge_Yo_` меняет раньше.

Правка существующего словаря: из `67_TTS_Offline АВТОР(phoneme).dic` удалено ошибочное
правило `свои=свой+и` (лишняя «й»); корректное `свои=сво+и` даёт `95.NEW_`.
