# Статус аудита

Дата: 2026-11-09.

## Открытые задачи

- Golden-корпус не гоняется в CI: словари gitignored и слишком велики для репозитория.
  Принято как ограничение; локально проверяется `--check-dictionaries` и ignored-тестом,
  дрейф словарей относительно манифеста даёт предупреждение.

## Закрыто в этом батче

- Provenance и манифест: `docs/DICTIONARIES.md`, `assets/dictionaries.sha256`,
  флаги `--manifest-dictionaries` и дрейф-предупреждения в `--check-dictionaries`.
- Лицензии: ссылки на тексты MIT/CC BY-SA/LGPL и источник eyo-kernel, заметки о модификациях.
- P3: Esc закрывает поиск при pending-cancel; toc/nav определяется по имени, а не подстроке;
  striping журнала непрерывен между батчами (`start_row(rows.start)`).
- Проверено, не проблема: sw-бэкенд поддерживает `ViewportCommand::CancelClose`.
- Релиз 0.1.9 опубликован (тег v0.1.9, GitHub Release с архивом и SHA256).

## Исправлено

- **№6 адаптивность.** Тулбар и статус-бар растут по содержимому, без `exact_size` в компактном режиме. UI-тесты проверяют 1000×640 при 16, 20 и 28 пт.
- **№16 виртуализация.** Чанки и отфильтрованный журнал замен рендерятся через `ScrollArea::show_rows`: в кадре остаются только видимые строки, при этом сохраняется горизонтальный скролл.
- **№17 отмена.** Отменяются чтение книги, компиляция словарей, проверка словарей и обработка текста. `Esc` и кнопка «Отмена» используют общий флаг.
- **№21 справка.** Тема, горячие клавиши и «О программе» доступны в Настройках; секция настроек прокручивается даже на минимальном окне.
- **№23 плотность сайдбара.** Свежая установка сворачивает группы словарей по умолчанию, состояние сохраняется.
- **№24 иконка окна.** Runtime-иконки берутся из мультиразмерного ICO и ставятся раздельно 16 и 32 px.
- Правка во время обработки, snapshot исходника и раздельные dirty-флаги.
- Пустой результат не экспортируется, а чанки пересобираются только после правок.
- EPUB читается через `container.xml` → OPF → spine.
- Метаданные FB2/EPUB/DOCX и сохранение исходника.
- Тема хранится одним значением с миграцией старых полей.
- Повреждённый `settings.json` сохраняется как копия.
- Ограничение размера архивов.
- `cargo fmt --check` и `cargo clippy --all-targets -- -D warnings` для обоих бэкендов.
- UI-тесты через `egui_kittest`.

## Проверено, не проблема

- Тяжёлые операции в UI-потоке для текущего набора задач.

## Принято

- Светлый TaskDialog — системное ограничение.
- Одноразовая HICON-утечка — стоимость фикса выше влияния.
- Чанки остаются отдельной функцией.
